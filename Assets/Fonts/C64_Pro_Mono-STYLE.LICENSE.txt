Use in Arkadia
--------------
The font file is embedded unmodified as an Avalonia resource (avares://Arkadia/Assets/Fonts/) and is used only to
draw the sidebar activity console. It is never installed system-wide and is not offered as a separate download.
It is covered by the "include this font as part of a software package" permission above ONLY while Arkadia is
freely provided to end users. If Arkadia is ever distributed commercially, a license must be negotiated with Style
first, or the font must be replaced.
